Afvinken → voorraad ophogen

Optie A: Afvinken vanuit productielijst

1. Vink een regel af ☑️
2. Pop-up vraagt: "Hoeveel stuks geproduceerd?"
3. Kies locatie waar neergelegd
4. Voorraad wordt automatisch opgehoogd
5. Regel verdwijnt uit productielijst
of

Optie B: Via Stalen + Voorraad

1. Klik "→ Voorraad" link op de regel
2. Wordt doorgestuurd naar Stalen + Voorraad
3. Gebruik snelle invoer om voorraad te boeken
4. Tekort verdwijnt automatisch uit productielijst
💡 Beide opties werken — optie A is sneller voor het afvinken, optie B gebruikt de bestaande snelle invoer. Beide updaten dezelfde voorraad.

Berekeningslogica

Backorder tekort:
nodig (uit orders) − afgewerkte voorraad = tekort
Toont alleen als tekort > 0
Onder minimum:
minimale voorraad − vrije voorraad = tekort
Toont alleen als vrije voorraad < minimum
Dit is een berekende view — geen eigen data, puur afgeleid van orders + voorraad + minimum instellingen
